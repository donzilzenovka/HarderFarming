# Harder Farming

Forge 1.7.10 project using the EntityGovernor RetroFuturaGradle 1.4.9 and Java 8 structure.

Scope: ordinary vanilla wheat, carrots and potatoes. Agricraft, Pam's HarvestCraft and nether wart are untouched. No items or weeds.

**Status: incomplete prototype.** Configuration and a stage-dependent risk function exist, but the world-tick handler does not yet apply mortality. Do not treat this branch as a working gameplay release.

Configuration is generated at `config/harderfarming.cfg`.
